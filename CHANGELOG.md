# Changelog

## 1.0.1 · Standalone source preview

- Published a fresh source archive for the standalone repository.
- Included the AGPL 3.0 license for original Waifu2x-Mac contributions and the preserved upstream notices.

## 1.0.0 · Source preview

- Ported the desktop app to Qt 6 on Apple Silicon with a four-step workflow, light and dark appearance, and a new app icon.
- Added MetalFX spatial upscaling alongside Real-CUGAN, Real-ESRGAN, and RealSR options for illustrations and photos.
- Added live comparison, scale and target-resolution controls, batch output settings, saved presets, and a results gallery.
- Retained GIF and video processing, with optional RIFE frame interpolation.
- Added a local engine check, data migration from earlier Mac builds, and a documented macOS bundle script.
